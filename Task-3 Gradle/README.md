# Java Application using Gradle

## Project Description
This project demonstrates how to build and run a Java application using Gradle.

## Tools Used
- Java 21
- Gradle 9.6.1
- IntelliJ IDEA

## Features
- Java application built with Gradle
- Dependency management using Gradle
- Easy build automation
- Ready for CI/CD integration

## How to Run

```bash
gradle run
```
